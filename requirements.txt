# llm-triage-boundaries — runtime dependencies
# Target: Python 3.11.x (3.10–3.13 supported) on Windows 11 / Linux / macOS
#
# ---------------------------------------------------------------------------
# PIN RATIONALE — read before you change anything here
# ---------------------------------------------------------------------------
# pydantic:
#   v2 API is mandatory (model_json_schema, field_validator, model_validator,
#   ConfigDict). 2.9 is the floor because `json_schema_extra` behaviour on
#   computed/annotated fields stabilised there; we rely on it to mark
#   "model-blind" fields that must never reach the prompt.
#
# ollama:
#   Schema-constrained decoding — passing a full JSON Schema object to
#   `format=` — requires ollama-python >= 0.4.4 AND Ollama server >= 0.5.0.
#   On 0.2.x, `format` only accepts the literal string "json", which performs
#   NO schema enforcement. You would get plausible-looking but structurally
#   wrong output and never notice. Do not downgrade this pin.
#
# tabulate:
#   Console tables in analyze.py. 0.9.0 added the "rounded_outline" style used
#   for the presentation-mode output.
# ---------------------------------------------------------------------------

pydantic>=2.9.0,<3.0.0
ollama>=0.4.7,<1.0.0
tabulate>=0.9.0,<1.0.0
